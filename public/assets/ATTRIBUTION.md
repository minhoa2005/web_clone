# Globe textures

- `earth-blue-marble.jpg` — NASA Blue Marble (Visible Earth), public domain. Resized to 2048×1024 and re-encoded as JPEG for delivery; derived from the copy shipped with the `three-globe` example assets.
- `earth-topology.png` — ETOPO1 bedrock relief, public domain (NOAA/NCEI), via the `three-globe` example assets.
- `earth-water.jpg` — ocean/land specular mask from the `three-globe` example assets, converted to grayscale JPEG.
- `earth-clouds.png` — cloud layer from the three.js example textures (`examples/textures/planets/earth_clouds_1024.png`), derived from NASA imagery.
- `night-sky.png` — star field from the `three-globe` example assets.
- `earth-dark.jpg` — retained dark texture from the original `three-globe` example assets (no longer used by the globe).

Political boundaries rendered on the globe come from `countries-50m.geojson` (Natural Earth, public domain) and are orientation aids, not historical borders.
